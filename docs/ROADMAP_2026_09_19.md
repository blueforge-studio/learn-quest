Each item lists: **what** is owed, **why it matters**, **what blocks it**,
and **the smallest honest first step**.

- **P1** — active user-visible gap; learner can hit it today
- **P2** — on the critical path to the next clean ship
- **P3** — deferred but won't get cheaper

Agentic files at `.claude/agents/` (cross-repo forge / git / packr / lfs
patterns) are the operational companion to this roadmap. Read
`.claude/agents/external-inputs.md` first to see what the agentic files
were synthesized from.
